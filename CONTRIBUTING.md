# Contributing to Raven

Thanks for helping make Raven better! All development happens in this
repository, and every change ships as part of Raven Browser.

## How to contribute

1. Fork this repository on GitHub.
2. Make your change in a new branch.
3. Open a pull request to this repository with a clear description.
4. The maintainer reviews it. Nothing is merged without approval.

Bug reports, ideas and translations are welcome too: open an issue.

If you do not agree, please do not submit a contribution.
